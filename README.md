# 🌅 Golden Hour Cat

A beautiful adaptive New Tab experience for Google Chrome, featuring a
high-resolution golden-hour cat background, glass-style search interface,
and a live clock.

![Golden Hour Cat](extension/images/Firefly_7680x4320.jpg)

## ✨ Features

- 🐱 Golden-hour cat photography
- 🖼️ High-resolution backgrounds up to 8K
- 🖥️ Adaptive background selection based on screen aspect ratio
- 🔎 Google Search directly from the New Tab page
- 🌐 Direct URL navigation from the search box
- 🕐 Live digital clock
- 🧊 Blue glass-style search interface
- 🌙 Dark visual design
- ⚡ Lightweight and dependency-free
- 🔒 No special browser permissions required

## 🖼️ Adaptive Backgrounds

Golden Hour Cat includes multiple background resolutions and automatically
selects a suitable image based on the browser window's aspect ratio.

| Resolution | Aspect Ratio | Intended Display |
|------------|--------------|------------------|
| 7680 × 4320 | 16:9 | Standard widescreen |
| 7680 × 4800 | 16:10 | 16:10 displays |
| 2368 × 1008 | Ultrawide | Ultrawide displays |
| 2048 × 1152 | 16:9 | Additional widescreen |

The background is selected dynamically when the New Tab page is opened or
the browser window is resized.

## 🚀 Installation

### Manual Installation

1. Download this repository or clone it:

   ```bash
   git clone git@github.com:Amir-1991/chrome-theme-golden-hour-cat.git
2.Open Google Chrome.

3.Navigate to:
  chrome://extensions
  
4.Enable Developer mode.

5.Click Load unpacked.

6.Select the extension directory from the repository.

7.Open a new tab.
